# Design System

## 1. Product Personality

The application should feel:

- Trustworthy
- Calm
- Professional
- Clear
- Modern
- Helpful

Avoid an overly flashy or gaming-style financial interface.

---

## 2. Core UX Principle

The user should understand their financial situation in seconds.

The dashboard should answer:

> How am I doing financially?

before showing detailed transaction information.

---

## 3. Visual Hierarchy

Priority:

1. Financial Health
2. Income / Expenses / Savings
3. Important Insights
4. Spending Breakdown
5. Spending Trends
6. Budgets
7. Savings Goals
8. Transactions

---

## 4. Color System

Use semantic colors.

### Primary

Main actions and important interactive elements.

### Background

Calm neutral application background.

### Surface

Cards, panels, modals, and elevated content.

### Success

Healthy financial states and positive progress.

### Warning

Budget warnings and attention-required insights.

### Danger

Budget exceeded states and critical errors.

### Text

Use clear contrast between:

- Primary text
- Secondary text
- Muted text
