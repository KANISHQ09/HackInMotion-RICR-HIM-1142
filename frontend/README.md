# Spendly Frontend

This is the Next.js frontend for Spendly.

## Stack

- Next.js 16.
- React 19.
- TypeScript.
- Tailwind CSS v4.
- shadcn/ui style components.
- Radix UI.
- lucide-react icons.
- Recharts.
- Framer Motion.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Useful Commands

```bash
npm run build
npm start
```

## Structure

```text
frontend/
  app/
  components/
  components/ui/
  lib/
  public/
```

## Design Guidance

Follow `docs/design.md` when creating new Spendly pages such as login, register, dashboard, transactions, budgets, and goals.

Use the repository/product name `Spendly` in user-facing UI and documentation.
